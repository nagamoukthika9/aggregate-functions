# SQL Data Analysis – Aggregation Functions

## Project Overview
This project focuses on analyzing order data using SQL aggregation functions in MySQL Workbench. The objective is to extract useful insights from the dataset by performing calculations and grouping records.

## Tools Used
- MySQL Workbench
- MySQL
- SQL

## Dataset
The dataset contains 30 order records with details such as:
- Order ID
- Customer ID
- Customer Name
- City
- Country
- Order Date
- Category
- Product Name
- Quantity
- Unit Price
- Status
- Order Amount

## SQL Concepts Practiced
1. COUNT() – Count total orders.
2. COUNT(DISTINCT) – Find unique customers.
3. AVG() – Calculate average quantity.
4. SUM() – Calculate total sales.
5. MIN() – Find minimum product price.
6. MAX() – Find maximum product price.
7. GROUP BY – Analyze orders by country.
8. GROUP BY – Calculate total quantity by product category.

## Project Tasks
- Imported the dataset into MySQL Workbench.
- Checked and corrected column data types.
- Executed SQL aggregation queries.
- Grouped data to generate meaningful summaries.
- Analyzed order and sales information.
